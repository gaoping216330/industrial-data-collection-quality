# 页面版本开发约定

- 运行入口由 web_app.py 的 / 路由选择 static/versions/1.0/index.html 或 static/versions/1.1/index.html。
- 页面样式和交互应编辑用户指定版本的 static/versions/<版本>/ 文件；根 static 的旧文件不是当前两个版本页面的入口。
- 1.0 和1.1的前端独立，禁止为了修改一个版本批量覆盖另一个版本。
- 后端接口、权限、数据库与采集共用。后端改动必须验证两个页面版本；页面切换不代表后端/数据库回退。
- 版本源码目录是源码快照，不是第二套正在运行的服务。不要启动重复采集进程。
- 版本地址、切换及源码说明见 页面版本开发说明.md。
