# 点位恒值检测独立开关

本地 gpwinccoa.autosensor.flatlineCheck：INT NOT NULL DEFAULT 0。0启用，任意非0值停用恒值检测。

1.1版异常点位列表、点位监测和点位明细显示恒值检测开关，仅管理员可以确认修改。数据库审计表 dq_flatline_setting_audit 记录EID、原值、新值、操作工号、IP和时间。

开关独立于 qualityCheck：不影响质量BAD、断线、模型判断、采集和趋势。停用点位不参与设备全部点位恒值的判定，其他参与点仍按设备规则判断。qualityCheck非0仍优先停用所有质量报警。

网页修改通知判定引擎重载；外部直接修改本地表每10分钟重读。正式判定仍按5分钟发布。现有恒值事件结束时注明检测停用，不代表现场恢复。

目录同步保留本地 flatlineCheck，源库不新增、不写入该字段。1.0页面保留原样，共享后端仍尊重新字段。
