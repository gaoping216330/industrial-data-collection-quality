# 设备人工异常原因

业务设备按部门、工序、设备、组对应的display_group_token唯一确定。采集标识数是COUNT(DISTINCT device_key)，用于表示同一业务设备下的采集标识数量，不是点位数量。

最早离线时间取当前已确认为“从未收到/停止发送”的关联点位中最早data_missing_since；从未收到的时间为本平台首次发现时间，无法追溯更早的真实断线。质量BAD等非缺数据异常不推测离线时间。

人工设备原因保存于gpwinccoa.dq_device_manual_reason，当前内容按device_token关联读取到设备和点位，不逐点复制，不被10分钟目录同步覆盖。系统判定原因保持独立。对应点位自动显示“异常原因（人工填写）”，可以在点位明细查看填写人和时间。原因保留至人工修改或清空，不会因数据恢复自动删除；设备分组元数据改变后的新token不自动继承旧设备备注。

管理员可从异常设备列表点击填写或修改。后端也验证管理员会话。编辑和清空均在dq_device_manual_reason_audit记录原内容、新内容、操作账号、IP、修改时间，与当前内容更新处于同一事务。保存不改变报警启停，不关闭异常事件。
