# 管理员与异常导出

右上角可登录管理员；初始用户名为 admin，初始密码由系统随机生成，见本目录“管理员初始登录.txt”。登录后点击管理员管理入口可修改密码或退出。密码修改后会退出登录。初始凭据请妥善保管，改密后可删除初始密码文件。超级管理员及新增工号账号的密码均以哈希保存于 admin_credentials.json；该文件不在静态网页目录中，不可通过网页下载，请勿删除（同时含会话签名密钥）。登录有效期8小时。

所有修改接口均在服务端验证管理员会话，包括报警启用/停用和判定规则。未登录可查看和导出，不能修改。报警屏蔽仍使用 autosensor.qualityCheck：1停用，0启用。停用不影响采集、趋势或模型计算。开关先写原始目录库，再同步到当前目录库；判定服务随后重载目录。已存在的事件按屏蔽关闭，历史保留，不标为数据恢复。

各页面右上角可导出全部异常 Excel；弹窗也可导出。导出沿用当前筛选，取全部分页记录而非当前页。点位页只导出正式异常；设备页导出有异常点位的设备；模型页导出异常/预警；事件页遵从来源和恢复状态；总览、判定配置、运行状态页导出全局异常点位。设备弹窗保留设备及异常类别筛选；点位趋势弹窗导出该点全部异常历史。文件为 .xlsx，冻结表头、可筛选、浮点数显示两位小数。

总览两个事件表固定高度460像素，可滚轮查看，达到底部自动加载下一批50条，表头保持固定。

## 按工号管理管理员

现有admin为唯一超级管理员，保留原密码。登录后点击右上角“管理”→“人员管理”。可按数字工号、姓名和初始密码（不限制长度，仅不能为空）新增普通管理员，也可修改姓名、停用、恢复、重置密码。为保留工号与历史审计关联，不物理删除账号。普通管理员具有报警启停、人工原因、判定配置等业务修改权限，但服务端禁止其访问人员列表、新增人员、管理任何账号或提升角色。超级管理员不能通过人员管理接口被停用或重置，需本人修改密码。

每个账号独立密码哈希及会话版本。停用、重置密码、修改账户资料后，旧会话下次访问即失效。本人可修改自己的密码，不影响其他人的登录。文件原子替换保存，重启后账号仍存在。工号、姓名、权限和状态可显示，密码与哈希不通过API返回。

账号新增、修改、停用/恢复、密码重置和本人改密会写入gpwinccoa.dq_admin_account_audit，包括操作者工号、目标工号、时间、IP、修改动作、状态和非敏感前后信息；不存明文密码或密码哈希。记录的REQUESTED状态表示尚未确认文件写入完成，SUCCESS为完成，FAILED为失败。账务写入失败时阻止人员修改。
