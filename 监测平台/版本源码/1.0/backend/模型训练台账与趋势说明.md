# 模型训练台账与趋势

模型页只显示已激活且 deployment_status=ready 的模型。共4196个，模型服务已实际加载4196个，所需输入9362个；不把“仅观察”或“需要校准”模型纳入实时判定。
离线验证是训练后的上线资格，不是实时判定。模型页可筛选正常、异常、无法判断、检测已停用，按健康度升降序排序，空分数最后。部门/工序与设备/组来自当前autosensor。

qualityCheck=0启用；非0停用该点位质量判定和报警，保留采集、历史和人工查看趋势。规则引擎将非0规范化为停用；模型每轮读取原始开关，停用目标不调用score_target，仍可作为其他模型的关联输入。该规则按2026-10-28用户最新要求覆盖先前“只停用报警、仍进行模型判定”的规则。界面立即按当前qualityCheck显示停用，模型执行以每轮读取的开关为准。管理员按钮仍经过原权限校验和审计。

数据库：
- dq_model_training_info：14903条摘要，含10612个已生成模型、4196个通过验证模型；保留原摘要JSON、文件SHA256及生成时间，不重新训练。
- dq_model_training_peer：数值关联和工况输入关联关系，relation_role区分numeric_peer/state_context；保留数值相关系数。去重后289410条关系。
- autosensorAI_training：以autosensor为主表、按EID联查训练信息的视图。包含company、department、process、equipment、group、point、model、tag、did、channel、qualityCheck；其他字段包含模型状态/方法/置信等级/验证结果/历史可用率/误差/离线异常率/关联EID/工况EID/历史范围/变化率阈值/训练来源与时间。目录变动自动反映；没有训练记录的点位显示未纳入本次训练，不伪造训练信息。

导入依据 outputs/all_sensor_typeai_ptf/models_53d/model_summary.csv 与 manifest.json；工况输入EID从309个本地模型文件的state_eids提取，可能包含BOOL或数值点。普通更新按顺序运行model_training_import.py、extract_training_contexts.py（Python3.12）、import_training_contexts.py。

点位详情保留原有信息，新增训练证据和关联曲线。目标用左轴原值，关联点各自在当前可见窗口内缩放，仅比较变化形态；标尺显示原始值与实际采样时间。默认不勾选关联点，仅读取本点位趋势；人工勾选后才读取关联趋势，所有关系仍列出可选；仅读取已勾选点，每次并发2个，实时关联曲线每15秒读取，目标实时值和趋势仍每5秒读取。没有历史数据的关联点明确显示无数据，不补造数值。
历史查询仍使用用户提供的秒/分钟/小时/天接口和3600条单次上限分批读取。切换趋势类型不自动发起历史查询，需点击查询历史。

趋势类型和历史粒度使用按钮。详情支持全屏。导出所选趋势Excel可选择当前可见时间窗口或全部已查询样本，包含目标和已勾选且已加载的关联曲线，保存原始值，不保存缩放后的绘图值。Excel按两位小数显示，底层保留原始精度，按时间和EID排序。此导出是只读POST，普通查看者可使用；设置修改仍要求管理员。单次最多64条曲线、15万采样，超出提示分批导出。未读取到数据不导出假值，历史未查询时不能导出不存在的样本。
