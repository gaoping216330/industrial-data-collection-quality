# 页面版本 1.0 / 1.1

- 1.0：/?version=1.0，前端源码 static/versions/1.0/。
- 1.1：/?version=1.1，前端源码 static/versions/1.1/。
- 右上角“页面版本”按钮切换，浏览器保存选择。无既有选择时默认1.1；直接带version参数的地址优先。
- 两版各自拥有完整独立的HTML、CSS、JavaScript文件，修改一个目录不会修改另一个；后续请明确指定版本。根目录static原文件也保留，不再作为这两版页面的入口。
- 1.1从总览移除最近未恢复点位事件；未恢复设备事件移到设备监测页，可点击跳转和滚动查看；总览统计分“部门与人员”“模型覆盖”两个视图。
- 数据库、接口、采集进程、账号权限与实时数据共用。页面切换不会创建第二套接收程序，不会切换或回退数据库。
- 版本源码/1.0/backend/保留开始改版时的监测平台后端Python/脚本/文档副本；版本源码/1.1/backend/保留1.1对应源码。manifest.json记录前端文件SHA256。
- 后端源码副本用于后续开发参考，不是正在并行运行的独立后端。两份快照不包括模型大文件、Redis/MySQL数据和打包Python运行时；不要把代码版本误当作数据备份。
